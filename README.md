## About this GitHub

This GitHub is not intended as a portfolio. It is primarily an archive of projects I completed during my studies at [42 Berlin](https://42berlin.com/).

The projects were developed as part of the curriculum, where documentation was not part of the requirements at the point. As a result, some repositories contain little or no documentation beyond what was necessary for the projects themselves.

I initially chose not to publish this code, as I wanted to avoid making the projects available while they could still be relevant to the curriculum. Since the curriculum has since evolved, I decided to make the repositories public and keep them here as an archive of my work and learning process.

For a documented overview of my work and a personal impression about my 42 journey , please visit my **[portfolio](https://portfolio-42.harold-ruiz-franck.workers.dev/)**.

If you would like more context or documentation for any of the projects, I would be happy to provide it.
